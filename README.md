# HU 스킬맵 프로토타입

시연용 프로토타입입니다. 화면의 점수·학습 데이터는 예시 값입니다.

스킬 기반 학습(Skill-Based Learning) 서비스의 UX/UI 방향을 검증하기 위한 디자인 시안용 프로토타입입니다.

현재 커리어에서 목표 커리어까지 가는 스킬 경로를 지도 위에 그려 주고, 지금 배울 스킬을 안내합니다.

데모: https://hunetcypark-alt.github.io/hu-skillmap/

단일 HTML 파일(index.html)로 동작합니다.

시연용입니다. 점수, 평균, 진행률 등 모든 수치는 예시 값이에요.

구성

컨셉: 출발(내 커리어) → 경유(관심 커리어) → 도착(목표 커리어)의 길 안내 UX

온보딩, 경로(타임라인, 저장한 경로 3개), 지도(내 경로 / 내 주변 / 직군별, 커리어 카드 확장, 내비게이션 바)

모바일·태블릿: 하단 탭바 + 바텀시트, 경로 안내 모드
